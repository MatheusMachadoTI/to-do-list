# 📋 ToDo List

Um aplicativo web moderno e responsivo para organização de tarefas diárias.

O objetivo deste projeto é oferecer uma experiência simples, intuitiva e agradável para ajudar os usuários a manterem suas tarefas organizadas.

> 🚧 Projeto em desenvolvimento.

---

# 📖 Sobre o projeto

O **ToDo List** foi desenvolvido com foco em praticar desenvolvimento Front-end e Back-end, aplicando boas práticas de programação, organização de código e versionamento com Git e GitHub.

Este projeto faz parte do meu portfólio e será desenvolvido seguindo um fluxo semelhante ao utilizado por equipes de desenvolvimento.

---

# ✨ Funcionalidades

- Cadastro de usuários
- Login
- Dashboard
- Criar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Barra de progresso
- Pesquisa de tarefas
- Filtro por categoria
- Filtro por prioridade
- Perfil do usuário
- Responsividade para desktop e dispositivos móveis
